# 🌀 My-Head (GitFlow, Pull Requests & GitHub Pages)

> Projeto desenvolvido como atividade prática de versionamento com **GitFlow**, criação de **Pull Requests**, padronização com **Template de PR** e publicação contínua no **GitHub Pages**.

🔗 **Acesse a página publicada no GitHub Pages:**  
👉 [https://borges2423.github.io/My-Head/](https://borges2423.github.io/My-Head/)

---

## 🚀 Tecnologias Utilizadas

- **HTML5** & **CSS3** (com variáveis CSS e efeito Glassmorphism)
- **JavaScript (ES6+)**
- **GSAP (GreenSock Animation Platform)** - Animação suave em 360°
- **Bootstrap 5** - Sistema de grid e componentes responsivos
- **Git & GitHub** - Fluxo baseado em GitFlow e deploy automatizado via GitHub Pages

---

## 🌿 Estrutura de Branches (GitFlow)

```text
main
│
└── develop
    │
    └── feature/personalizar-home
```

- **`main`**: Versão estável em produção, conectada diretamente ao GitHub Pages.
- **`develop`**: Branch de integração onde todas as features são consolidadas e testadas antes do deploy.
- **`feature/personalizar-home`**: Branch de desenvolvimento de funcionalidades com commits semânticos:
  - `feat: adiciona cabeçalho da página`
  - `style: melhora layout da página principal`
  - `feat: adiciona links de contato`

---

## 📋 Template de Pull Request

O repositório conta com o template padronizado em `.github/PULL_REQUEST_TEMPLATE.md` contendo:
- Objetivo
- Mudanças
- Como testar
- Checklist de validação
